## 使用方法

> [!NOTE]
> 请先安装 `fastfetch`  
> ArchLinux:  
> ``` sh
> yay -S fastfetch
> ```
> Ubuntu:  
> ``` sh
> sudo apt upgrade && sudo apt install fastfetch
> ```


``` sh
git clone git@github.com:dev-kai0602/MyFastfetchConfig.git
cd MyFastfetchConfig
cp -r ./* $HOME/.config/fastfetch
```
